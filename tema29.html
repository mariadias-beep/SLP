29. Tratamento de erros e validação de dados

Conteúdos para estudo

Valide sempre as entradas. Se o utilizador escrever texto onde se esperava um número, cin falha: limpe o erro e descarte a entrada.

int n;
while (!(cin >> n) || n < 1 || n > 10) {
    cout << "Valor inválido (1-10). Tente de novo: ";
    cin.clear();
    cin.ignore(1000, '\n');
}

Mensagens de erro claras ajudam o utilizador.
