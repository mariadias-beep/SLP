14. Funções: conceito, declaração, parâmetros e retorno

Conteúdos para estudo

Uma função é um bloco de código com nome, reutilizável. Tem tipo de retorno, nome e parâmetros.

int quadrado(int x) {
    return x * x;
}
void saudar() { cout << "Olá"; }
int main() { cout << quadrado(5); saudar(); }
  • void = não devolve valor
  • return devolve o resultado
  • reutilizar código evita repetições
