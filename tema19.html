19. Pesquisa e ordenação de vetores

Conteúdos para estudo

Pesquisa linear: percorre o vetor até encontrar o valor. Ordenação por bolha (bubble sort): compara pares vizinhos e troca se estiverem fora de ordem.

int pos = -1;
for (int i = 0; i < n; i++)
    if (v[i] == x) { pos = i; break; }

for (int i = 0; i < n - 1; i++)
  for (int j = 0; j < n - 1 - i; j++)
    if (v[j] > v[j+1]) { int t = v[j]; v[j] = v[j+1]; v[j+1] = t; }
