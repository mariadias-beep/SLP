2. Algoritmo, programa e sintaxe básica

Conteúdos para estudo

Um algoritmo é uma sequência finita e ordenada de passos que resolve um problema. Um programa é a implementação do algoritmo numa linguagem.

Sintaxe básica: C/C++ distingue maiúsculas de minúsculas; os blocos usam { }; cada instrução termina em ;.

// Algoritmo: somar dois números
// 1. Ler a e b   2. soma = a + b   3. Mostrar soma
#include <iostream>
using namespace std;
int main() {
    int a = 2, b = 3;
    cout << a + b;
}
