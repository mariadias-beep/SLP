9. Operador ternário e condições compostas

Conteúdos para estudo

O operador ternário é um if/else numa expressão: condição ? valorSeVerdadeiro : valorSeFalso.

Condições compostas combinam testes com && e ||.

int idade = 20;
string estado = (idade >= 18) ? "adulto" : "menor";
if (idade >= 18 && idade < 65) cout << "ativo";

Use o ternário só em decisões simples, para não prejudicar a legibilidade.
