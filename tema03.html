3. Variáveis, constantes e tipos de dados

Conteúdos para estudo

Uma variável é um espaço de memória com nome e tipo. Tipos básicos: int (inteiros), float e double (reais), char (um carácter) e bool (verdadeiro/falso).

Uma constante não pode mudar: const double PI = 3.14159;

int idade = 17;
float altura = 1.75f;
double pi = 3.14159;
char letra = 'A';
bool ativo = true;
  • declarar: indicar tipo e nome
  • inicializar: dar o primeiro valor
  • nomes: sem espaços, sem começar por número
