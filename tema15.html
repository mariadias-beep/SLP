15. Funções com diferentes tipos de parâmetros e retorno

Conteúdos para estudo

As funções podem receber e devolver int, double, char, bool... O protótipo declara a função antes do main.

bool parOuImpar(int n);   // protótipo
double media(double a, double b) { return (a + b) / 2; }
bool parOuImpar(int n) { return n % 2 == 0; }

Ao chamar, os argumentos devem corresponder aos parâmetros em número e tipo.

Atividade 15 – “soma, media, maior, menor, parOuImpar”

Crie as funções soma(), media(), maior(), menor() e parOuImpar().
