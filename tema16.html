16. Âmbito das variáveis e organização do programa

Conteúdos para estudo

Variáveis locais existem só na função/bloco onde são declaradas; globais são declaradas fora das funções e vistas por todas (usar com moderação).

int total = 0;            // global
void somar(int x) {
    int dobro = x * 2;    // local
    total += dobro;
}

Organização: includes, constantes, protótipos, main, definição das funções.
