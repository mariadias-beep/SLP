6. Conversão de tipos e precedência

Conteúdos para estudo

Na divisão de dois inteiros o resultado é inteiro: 7/2 dá 3. Para obter 3.5 converta um dos operandos: 7/2.0 ou (double)7/2 ou static_cast<double>(a)/b.

Precedência (da maior para a menor): (), * / %, + -, relacionais, &&, ||, atribuição.

int a = 7, b = 2;
cout << a / b;           // 3
cout << (double)a / b;   // 3.5
cout << 2 + 3 * 4;       // 14
