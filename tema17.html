17. Arrays/vetores unidimensionais

Conteúdos para estudo

Um vetor guarda vários valores do mesmo tipo em posições consecutivas. O primeiro índice é 0.

int v[5] = {10, 20, 30, 40, 50};
cout << v[0];                  // 10
for (int i = 0; i < 5; i++) cout << v[i] << " ";
int n[3];
for (int i = 0; i < 3; i++) cin >> n[i];

Um vetor de tamanho 5 tem índices 0 a 4; aceder a v[5] é um erro.
