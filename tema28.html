28. Ficheiros e persistência de dados

Conteúdos para estudo

Persistência é manter os dados depois de o programa terminar. Guarda-se cada registo numa linha e carrega-se no arranque.

void guardar(Aluno t[], int n) {
  ofstream f("alunos.txt");
  for (int i = 0; i < n; i++) f << t[i].nome << " " << t[i].nota << endl;
}

Use o modo ios::app para acrescentar sem apagar o conteúdo.
