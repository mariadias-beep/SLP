31. Desenvolvimento de menus e aplicações de consola

Conteúdos para estudo

Uma aplicação de consola típica repete um menu até o utilizador sair, usando do while, switch e funções.

int op;
do {
    cout << "1-Adicionar 2-Listar 0-Sair: ";
    cin >> op;
    switch (op) {
      case 1: adicionar(); break;
      case 2: listar(); break;
    }
} while (op != 0);
