25. Ponteiros e passagem de parâmetros por referência

Conteúdos para estudo

Por omissão os parâmetros são passados por valor (cópia). Para alterar a variável original use ponteiros ou referências (&, em C++).

void troca(int &a, int &b) { int t = a; a = b; b = t; }
void trocaP(int *a, int *b) { int t = *a; *a = *b; *b = t; }
// troca(x, y);   trocaP(&x, &y);
