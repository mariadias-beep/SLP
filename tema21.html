21. Strings e manipulação de texto

Conteúdos para estudo

Em C++ use string (#include <string>); em C usam-se char[] terminados em '\0'.

string s = "programar";
cout << s.length();      // 9
cout << s[0];            // p
if (s == "programar") cout << "igual";
int vogais = 0;
for (char c : s) if (c=='a'||c=='e'||c=='i'||c=='o'||c=='u') vogais++;

Em C: strlen, strcmp, strcpy (<cstring>).
