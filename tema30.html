Divida o programa em módulos: o ficheiro .h (cabeçalho) declara funções e o .cpp define-as.

// utils.h
int soma(int a, int b);
// utils.cpp
#include "utils.h"
int soma(int a, int b) { return a + b; }
// main.cpp
#include "utils.h"

Compilar: g++ main.cpp utils.cpp -o programa
