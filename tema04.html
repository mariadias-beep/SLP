4. Entrada e saída de dados

Conteúdos para estudo

Em C++: cout << valor escreve e cin >> variável lê. Em C: printf("%d", x) e scanf("%d", &x). Formatos: %d int, %f float, %lf double, %c char.

#include <iostream>
using namespace std;
int main() {
    int ano, nasc;
    cout << "Ano atual: "; cin >> ano;
    cout << "Ano de nascimento: "; cin >> nasc;
    cout << "Idade: " << ano - nasc << endl;
}

Para ler frases com espaços use getline(cin, texto);.
