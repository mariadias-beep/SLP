18. Processamento de vetores

Conteúdos para estudo

Percorra o vetor com um for para acumular resultados.

int soma = 0, max = v[0], min = v[0];
for (int i = 0; i < n; i++) {
    soma += v[i];
    if (v[i] > max) max = v[i];
    if (v[i] < min) min = v[i];
}
double media = (double)soma / n;
