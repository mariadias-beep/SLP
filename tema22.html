22. Estruturas struct

Conteúdos para estudo

Uma struct agrupa dados de tipos diferentes num só registo.

struct Aluno {
    string nome;
    int numero;
    double nota;
};
Aluno a;
a.nome = "Ana"; a.numero = 5; a.nota = 16.5;
cout << a.nome << " " << a.nota;

Os campos acedem-se com o operador ..
