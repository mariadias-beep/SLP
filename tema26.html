26. Gestão dinâmica de memória – conceitos

Conteúdos para estudo

Com new reserva-se memória durante a execução; com delete liberta-se. Para vetores: new[] e delete[].

int *p = new int;
*p = 5;
delete p;

int n = 4;
int *v = new int[n];
for (int i = 0; i < n; i++) v[i] = i * 2;
delete[] v;

Memória reservada e nunca libertada causa fugas de memória.
