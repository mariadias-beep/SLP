8. Estrutura switch

Conteúdos para estudo

O switch escolhe entre várias opções fixas (int ou char). Cada case termina com break; default trata os restantes casos.

char op;
cin >> op;
switch (op) {
  case '+': cout << a + b; break;
  case '-': cout << a - b; break;
  default: cout << "Opção inválida";
}

Sem break a execução continua no case seguinte.
