11. Ciclos while e do while

Conteúdos para estudo

while testa a condição antes de cada repetição; do while executa pelo menos uma vez e testa no fim.

int n;
do {
    cout << "Idade (0-120): ";
    cin >> n;
} while (n < 0 || n > 120);

Usam-se quando não se sabe quantas repetições serão necessárias (por exemplo, validar dados).
