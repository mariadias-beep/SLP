5. Operadores aritméticos, relacionais e lógicos

Conteúdos para estudo

  • Aritméticos: + - * / % (resto da divisão)
  • Relacionais: == != < > <= >= (resultado bool)
  • Lógicos: && (e), || (ou), ! (não)
  • Atribuição composta: += -= *= ++ --
int a = 7, b = 3;
cout << a % b;              // 1
cout << (a > b && b > 0);   // 1 (verdadeiro)

Atenção: = atribui, == compara.
