10. Ciclo for

Conteúdos para estudo

O for repete um bloco um número conhecido de vezes: inicialização; condição; incremento.

for (int i = 1; i <= 10; i++) {
    cout << i << " x 2 = " << i * 2 << endl;
}
int soma = 0;
for (int i = 1; i <= 100; i++) soma += i;
  • i++ equivale a i = i + 1
  • cuidado com ciclos infinitos
