27. Ficheiros: leitura e escrita de dados

Conteúdos para estudo

Com <fstream>: ofstream escreve e ifstream lê ficheiros de texto.

#include <fstream>
ofstream out("dados.txt");
out << "Ana 16" << endl;
out.close();

ifstream in("dados.txt");
string nome; int nota;
while (in >> nome >> nota) cout << nome << nota;
in.close();
