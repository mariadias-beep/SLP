20. Matrizes bidimensionais

Conteúdos para estudo

Uma matriz tem linhas e colunas: int m[3][3];. Percorre-se com dois ciclos aninhados.

int m[2][3] = {{1,2,3},{4,5,6}};
for (int l = 0; l < 2; l++) {
    int soma = 0;
    for (int c = 0; c < 3; c++) soma += m[l][c];
    cout << "Linha " << l << ": " << soma << endl;
}

Para somar por coluna, o ciclo exterior percorre as colunas.
