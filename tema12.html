12. Ciclos aninhados

Conteúdos para estudo

Um ciclo dentro de outro: o ciclo interior executa por completo a cada volta do exterior.

for (int l = 1; l <= 4; l++) {
    for (int c = 1; c <= l; c++) cout << '*';
    cout << endl;
}
